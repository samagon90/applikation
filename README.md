# Arena AI — Android-приложение

Нативное Android-приложение (Kotlin), которое оборачивает сайт
**https://arena.ai** в WebView, с современным интерфейсом в стиле
лучших AI-приложений (ChatGPT / Claude / Perplexity) и встроенным
обходом блокировок: **автоматический прокси** и **режим зеркала**.

| Параметр        | Значение               |
|-----------------|------------------------|
| applicationId   | `ai.arena.webapp`      |
| minSdk          | 26 (Android 8.0)       |
| targetSdk       | 35 (Gradle) / 29 (оффлайн-сборка) |
| Язык            | Kotlin                 |
| Зависимости     | **нет** (только платформенные API) |
| Версия          | 2.3.0 (versionCode 6)  |

Готовый установочный файл v2.3.0: **`dist/ArenaAI-release.apk`**
(собран без Android SDK — см. «Сборка без Android SDK»).
APK прошлой версии: `dist/ArenaAI-v1.0.0.apk`.

## Что нового в 2.0

### 🎨 Интерфейс в стиле iOS

Дизайн переработан по мотивам последнего iOS: системные цвета
(systemBlue/systemGreen/systemGray), карточки с разделителями-волосками,
шрифты и анимации как в нативных iOS-приложениях.

- **Фиксированные панели** (верхняя навигация + нижний toolbar) —
  контент сайта никогда не перекрывается элементами интерфейса.
- **Верхняя панель**: центрированный заголовок с подзаголовком статуса
  подключения, кнопка «назад» появляется как в iOS Safari.
- **Нижний toolbar**: назад / вперёд / обновить / подключение (со
  статусной точкой) / поделиться; неактивные кнопки приглушены.
- **Прогресс-бар** в стиле iOS Safari (тонкая синяя полоска).
- **Шторка «Подключение»** — настоящий iOS bottom sheet: граббер,
  пружинное появление (overshoot), свайп вниз для закрытия,
  ограничение высоты с прокруткой содержимого.
- **UISegmentedControl** для режимов: Авто | Прямо | Прокси | VPN —
  серая подложка со скользящей белой «таблеткой» и тенью.
- **UISwitch** для зеркала: анимированная зелёная «таблетка» iOS.
- **Оффлайн-экран** с крупным заголовком, иконкой в круге и
  прокруткой (работает на любых экранах).
- **Тёмная/светлая тема** по системной настройке, палитра iOS
  (systemGray6 фоны, #1C1C1E карточки в тёмной теме).

### 🛡 Встроенный обход блокировок

Если arena.ai недоступен (например, в России), приложение
восстанавливает доступ автоматически. Четыре режима подключения:

| Режим | Как работает |
|---|---|
| **Авто** (по умолчанию) | Напрямую; при ошибке загрузки само включает зеркало (если настроено) или встроенный пул прокси |
| **Напрямую** | Без прокси |
| **Зеркало** | Через ваше собственное зеркало — бесплатный Cloudflare Worker (см. `mirror/`) |
| **Прокси** | Всегда через встроенный пул бесплатных прокси |
| **VPN (SOCKS5)** | Настоящий VPN: сам качает списки SOCKS5-прокси из интернета, проверяет их и гоняет через них весь трафик устройства |

**Пул прокси:**
- список скачивается с 3 публичных источников (TheSpeedX через jsDelivr,
  ProxyScrape, Geonode);
- на устройстве каждый прокси проверяется по-настоящему: CONNECT-туннель
  + TLS-хендшейк к arena.ai; остаются только живые, выбираются самые
  быстрые;
- применяется через официальный механизм WebView
  (`android.webkit.ProxyController` через `WebViewFactory` — тот же вызов,
  что делает androidx.webkit) — проксируется весь WebView, включая
  WebSocket-стриминг ответов моделей; на Android 8–9 без этого API
  используется системный `android.net.ProxyController` через рефлексию;
- если прокси «умирает», приложение само пробует следующий из пула.

**VPN (SOCKS5) — рабочий автоматический VPN.** Тот же подход, что
у CyberPortal X (режим «локальный сокс»): приложение **само скачивает
списки SOCKS5-прокси из интернета** (TheSpeedX socks5 через jsDelivr,
ProxyScrape socks5, Geonode socks5), **проверяет каждый на устройстве**
(SOCKS5-хендшейк + CONNECT к arena.ai + TLS через туннель) и поднимает
настоящий VPN через `VpnService` (TUN). Весь трафик устройства идёт
через рабочий прокси по схеме tun2socks:

- при включении — автоматический поиск и подключение к самым быстрым
  рабочим SOCKS5;
- если прокси падает — автоматический переход на следующий из пула,
  а пул обновляется в фоне;
- DNS через виртуальные IP: прокси резолвит домены сам (CONNECT с
  именем домена), ничего не резолвится локально;
- WebSocket-стриминг сайта работает (TCP-туннель), QUIC отбрасывается —
  браузер автоматически переходит на TCP.

Криптографическое ядро WireGuard/WARP (X25519, ChaCha20-Poly1305,
BLAKE2s, Noise IK) остаётся в репозитории как задел — оно проверено
тестами по RFC-векторам, но VPN-сервис теперь использует SOCKS5.
Все тесты: `scripts/test_vpn.sh` (45 тестов: криптография + эхо через
mock-SOCKS5-сервер).

**Зеркало (рекомендуется для стабильной работы):** бесплатный
Cloudflare Worker, который прозрачно проксирует arena.ai (включая
WebSocket и SSE). Развёртывается за 5 минут — инструкция в
[`mirror/README.md`](mirror/README.md). В режиме «Авто» зеркало
используется первым при недоступности сайта.

> ⚠️ **Публичные прокси — добровольная инфраструктура**: скорость и
> доступность не гарантируются, а владелец прокси технически видит
> домены, к которым вы обращаетесь (содержимое HTTPS — нет). Для
> входа в аккаунт предпочтительнее режим зеркала. Приложение не
> собирает и никуда не отправляет ваши данные.

### 🧩 Прочее

WebView (JS, DOM storage, cookies, кэш), загрузка/скачивание файлов,
полноэкранное видео, камера/микрофон, сохранение состояния при повороте,
локализации en/ru, только HTTPS. **Никаких сторонних библиотек** —
только платформенные API, поэтому APK маленький и собирается полностью
оффлайн.

## Сборка

### Обычная (Gradle + Android SDK)

Требования: JDK 17, Android SDK platform 35, интернет для Gradle.

```bash
./gradlew assembleRelease
# результат: app/build/outputs/apk/release/app-release.apk
```

### Без Android SDK (полностью оффлайн)

Готовый пайплайн `scripts/offline_build.sh` повторяет сборку вручную:
`aapt2 → kotlinc → dx → jarsigner`. Все инструменты берутся из
доступных источников (npm, исходники на GitHub) — полная инструкция
по их получению: [`scripts/offline_toolchain.md`](scripts/offline_toolchain.md).

```bash
export JAVA_HOME=/path/to/jre17
export KOTLIN_COMPILER_JAR=/path/to/kotlin-compiler.jar
export KOTLIN_STDLIB_JAR=/path/to/kotlin-stdlib-clean.jar
export AAPT2=/path/to/aapt2
export ANDROID_JAR=/path/to/framework-fixed.jar
export FRAMEWORK_RES=/path/to/framework-res.apk
export DX_CLASSES=/path/to/dx-classes
bash scripts/offline_build.sh
# результат: dist/ArenaAI-release.apk (подписан keystore из репозитория)
```

> Примечание: оффлайн-вариант собирается против Android 9 (API 28/29)
> framework, поэтому APK имеет `targetSdk 29`; Gradle-сборка использует
> полноценный SDK и `targetSdk 35`.

## Подпись

Release подписывается сгенерированным keystore
`app/keystore/release.keystore`:

- alias: `arena`
- store/key password: `arenaai123`
- сертификат: `CN=Arena AI, OU=Mobile, O=Arena, C=SG`, RSA-2048

> **Для публикации** замените keystore своим и обновите `signingConfigs`
> в `app/build.gradle.kts` (пароли вынесите в переменные окружения).

## Установка на устройство

```bash
adb install dist/ArenaAI-release.apk
```

Либо передайте APK на телефон (мессенджер, USB, облако), откройте файл
и разрешите установку из неизвестных источников. Android 8.0+.

## Ограничения

- Это WebView-обёртка: контент полностью зависит от сайта arena.ai.
- Push-уведомления (FCM) не реализованы.
- Скачивания идут через системный `DownloadManager`, который **не**
  затрагивается прокси приложения.
- На Android 8–9 прокси включается через системный API (рефлексия) —
  на редких прошивках может не сработать; в этом случае используйте
  зеркало или встроенный VPN (работает на всех версиях).
- Встроенный VPN перехватывает весь трафик устройства (системный
  запрос разрешения) и работает через публичные SOCKS5-прокси:
  скорость зависит от качества прокси, а владелец прокси видит
  домены назначения (содержимое HTTPS — нет). UDP/QUIC не
  туннелируется (браузеры автоматически переходят на TCP).
- Если хотите полноценный VPN вместо прокси: Psiphon SDK (бесплатная
  GPL-библиотека для встраивания) — конфиг выдаётся после запроса на
  psiphon.com. Код приложения к этому готов (ProxyManager изолирован).
- Google Play может отклонять приложения с обходом блокировок —
  распространяйте APK напрямую.
