# Бесплатное зеркало arena.ai (Cloudflare Worker)

Если arena.ai заблокирован в вашей сети, самый надёжный способ —
собственное зеркало на Cloudflare Workers. Это бесплатно, занимает 5 минут
и работает без лимитов по скорости: весь трафик (включая стриминг ответов
моделей через WebSocket/SSE) идёт через серверы Cloudflare.

## Развёртывание (5 минут)

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com)
   (бесплатно, email подтверждение).
2. Слева выберите **Workers & Pages → Create → Create Worker**.
3. Дайте воркеру любое имя, например `arena-mirror`, нажмите **Deploy**.
4. Нажмите **Edit code** и полностью замените содержимое редактора кодом
   из файла [`arena-proxy-worker.js`](arena-proxy-worker.js).
5. Нажмите **Deploy**.
6. Вверху страницы будет адрес вида:
   `https://arena-mirror.<ваш-аккаунт>.workers.dev` — скопируйте его.

## Подключение в приложении

1. Откройте Arena AI → нажмите на чип статуса подключения справа сверху
   (или откройте «Способы подключения» на экране ошибки).
2. Вставьте URL воркера в поле «Ваше зеркало» и нажмите «Сохранить».
3. Выберите режим **«Зеркало»** — или оставьте **«Авто»**: тогда зеркало
   включится само, если сайт не откроется напрямую.

## Как это работает

Worker принимает запросы на ваш поддомен, меняет Host на `arena.ai`
и перенаправляет их на оригинальный сайт. Ответы приходят с IP Cloudflare,
поэтому блокировка на стороне провайдера не срабатывает. Авторизация
(cookie) сохраняется на домене зеркала — вы можете войти в аккаунт Arena
как обычно.

## Ограничения бесплатного тарифа

- 100 000 запросов в день — для личного использования с запасом.
- Если зеркало станет общедоступным и им будут пользоваться сотни людей,
  лимит может быть исчерпан; в этом случае создайте ещё один воркер.

## Примечание

- Worker не хранит и не логирует ваши данные по умолчанию (код выше —
  «прозрачный», без записи чего-либо куда-либо).
- Если arena.ai снова станет доступен напрямую, просто переключите режим
  на «Напрямую» или «Авто».
